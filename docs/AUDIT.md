# Frontend bug audit

All backend requests now use the configured `NEXT_PUBLIC_API_URL` and the same authenticated RTK Query transport. Legacy direct-fetch views use a compatibility adapter; employee and leave screens use domain query/mutation hooks. HTTP-200 business failures are rejected before entering the cache. Logout removes legacy tokens and API keys, revokes the active server token when reachable, and clears RTK Query data. Changing accounts also clears cached data.

Employee lists and leave lists accept empty results and show loading/errors instead of demo employees. Salary zero and blank bank fields remain zero/blank in employee display and editing. New employee accounts require an explicit password of at least eight characters and no random bank account is generated. Leave writes display success only after the server confirms persistence; server IDs and state transitions are used. Invented leave balances are removed. Existing paid statements now use the backend's stored amounts.

Public self-registration into the shared company is disabled; contact HR for an account. Inherited recruitment, HR setup, devices, performance, accounting, requests/shifts/outwork, loans, notices and sales views are blocked by default because they contain demo data or incomplete persistence. `NEXT_PUBLIC_ENABLE_DEMO_PREVIEWS=true` exposes these only for intentional preview; do not enable it for production. The backend additionally blocks inherited controllers in production. Factory units/lines/shifts/grades, production and action records remain available through the real factory APIs. Inherited employee sub-tabs are also blocked by default; bulk salary/archive tools require real persistence before use.

Full ESLint reports zero errors; inherited unused imports/variables and hook dependency warnings remain. TypeScript, import/transport tests and the production build pass. Backend deployment settings are documented in `HRM-PHP-Backend/docs/AUDIT_AND_DEPLOYMENT.md`. No production Render/Vercel deployment or real bank payment was performed.
